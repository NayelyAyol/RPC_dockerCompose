No te cambio la lógica del código. El problema es solo la conexión de puertos.

Ahora mismo tienes:

Servidor Python
servidor = SimpleXMLRPCServer(("0.0.0.0",9000))

Eso significa:

Dentro del contenedor el servidor escucha en el puerto 9000.

Docker Compose

Tienes:

ports:
  - "8000:9000"

Esto significa:

PC:8000  --->  CONTENEDOR:9000

Es decir, desde tu máquina entrarías por localhost:8000.

PERO...

Tu cliente está dentro de otro contenedor:

cliente_xmlrpc = xmlrpc.client.ServerProxy("http://servidor:8000/")

Aquí está el error.

Dentro de Docker el cliente NO usa el puerto externo (8000), usa el puerto interno del servicio (9000).

Cambia solamente esta línea:

cliente_xmlrpc = xmlrpc.client.ServerProxy("http://servidor:9000/")

Nada más.
